# Sponsor SnaKédex Open Data API

**[❤️ Sponsor on GitHub → github.com/sponsors/0xcucumbersalad](https://github.com/sponsors/0xcucumbersalad)**

The [SnaKédex Open Data API](https://ph-snake-open.edgie.workers.dev) is a free, open, no-key API serving **10,426 expert-verified snake sightings** from across the Philippines. It's built and maintained in the open, and it runs at no cost to the people who use it — students, researchers, journalists, and hobbyists.

If it's useful to you or your project, please consider sponsoring. Your support directly keeps the data free and the lights on.

## Why sponsor

- **Keep it free and key-less.** No paywalls, no sign-ups, no rate-limit upsells. Sponsorship is what makes that sustainable.
- **Cover running costs.** Hosting (Cloudflare Workers), the image CDN, and the domain aren't free.
- **Fund ongoing work.** Time spent verifying identifications, correcting the record, expanding coverage, and improving the API and docs.
- **Support open data.** Everything is released under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) — free to use, including commercially.

## Where your support goes

| Area | What it funds |
| --- | --- |
| Infrastructure | Cloudflare Workers, image CDN, and domain costs |
| Data quality | Moderator time verifying and correcting species identifications |
| Coverage | Adding new sightings and provinces to the dataset |
| Development | New API features, better docs, and long-term maintenance |

## Ways to help (that aren't money)

Not everyone can sponsor, and that's completely fine. You can also:

- ⭐ **Star the repo** so more people find it.
- 🐛 **Report bugs or bad identifications** by [opening an issue](https://github.com/0xcucumbersalad/ph-snake-open/issues).
- 🔧 **Contribute** improvements via pull request.
- 📣 **Credit and link back** to SnaKédex when you use the data — attribution is all the license asks for, and it helps enormously.
- 💬 **Spread the word** to anyone working with Philippine biodiversity, herpetology, or open data.
